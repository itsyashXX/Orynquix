# Ram Singh Kaida — V6 Public Service Profile

A multi-page Vite + React public-information website concept with separate routes for About, Biography, Journey, Bhimtal, Public Service, Media, Gallery, Vision and Contact.

## Run
```bash
npm install
npm run build
npm run dev
```

## Deployment
Vercel is configured with an SPA rewrite so direct routes such as `/biography` and `/journey` resolve correctly.

## Content note
Career dates and role information should be rechecked against current official government records before production publication. The site is an independent informational concept, not an official government portal.
